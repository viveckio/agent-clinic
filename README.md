# AgentClinic

## Local development

### Requirements

- Node.js 22.12 or newer
- npm

### Start the app

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a current stable desktop or mobile browser. The first page is intentionally a neutral placeholder while the application foundation is established.

### Production build

```sh
npm run typecheck
npm run build
npm run start
```

No environment variables or database configuration are required for this placeholder.

## Input from stakeholders

- Mary in engineering wants a reliable site with a popular stack based on TypeScript, giving agents and staff a dashboard for easy access.
- Susan in product has a set of features about agents and their ailments, therapies, and booking appointments.
